# Rizmi — Personal Portfolio

Personal portfolio website built to introduce myself, showcase my skills, and document the projects I have worked on.

## About

Hi, I'm **Rizmi**, a Computer Engineering student with an interest in web development, programming, and technology.

This portfolio is a simple representation of my journey in learning and building things with technology.

## What You'll Find

* Personal introduction
* Skills and technologies
* Selected projects
* Education and experience
* Contact and social links

## Tech Stack

* HTML5
* CSS3
* JavaScript

The website is built from scratch without relying on a large frontend framework. The focus is on keeping the interface simple, responsive, and easy to maintain.

## Design

The portfolio uses a dark and minimal visual style with a combination of navy, crimson, and gold accents.

The design is intentionally kept simple so the content remains the main focus.

## Project Structure

```text
portfolio/

├── script.js
├── assets/
│   ├── images/
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/USERNAME/portfolio.git
```

Open the project folder and run `index.html` in your browser.

For development, you can also use Live Server in Visual Studio Code.

## Responsive

The website is designed to work across different screen sizes, including desktop, laptop, tablet, and mobile devices.
